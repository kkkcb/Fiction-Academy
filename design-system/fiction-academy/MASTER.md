# Fiction Academy 设计系统

## 产品定位
沉浸式 AI 小说创作平台。用户是网文/小说作者，需要长时间专注写作、梳理剧情、管理设定。界面应该营造"文学工作室"的高级感，减少干扰，突出内容本身。

## 设计关键词
content-first, literary, warm, premium, calm, immersive, sophisticated

## 风格方向
**"暖调文学编辑器"**：深色与浅色双主题，以纸质/羊皮纸质感为灵感，克制的高级橙铜色作为强调，避免花哨渐变和圆角滥用。使用大量留白、精确的字重对比和细腻的边框/阴影层次。

## 色彩系统

### 浅色主题
- 背景层：`#fbfaf9`（页面底） `#f5f2ee`（卡片底） `#ffffff`（输入区/弹窗）
- 强调色：`#c55d3b`（主） `#a64a2e`（hover） `#f3e7e1`（浅背景）
- 文字：`#1a1715`（主） `#5e5853`（次） `#9c9690`（第三）
- 边框：`#e8e4e0`（主） `#f1edea`（轻）
- 成功/状态：`#2d7a5e` `#b8860b` `#8b5a2b`

### 深色主题
- 背景层：`#12100e`（页面底） `#1a1714`（卡片底） `#211d19`（输入区/弹窗）
- 强调色：`#d98b6e`（主） `#e6a88e`（hover） `#3d2a21`（浅背景）
- 文字：`#f3f0ed`（主） `#b8b0a8`（次） `#6b655e`（第三）
- 边框：`#2d2824`（主） `#24201c`（轻）

## 字体系统
- 标题：`Noto Serif SC`（衬线，书卷气）
- 正文/UI：`Noto Sans SC`（无衬线，高可读性）
- 标签/代码/数据：`JetBrains Mono`

## 字号层级
- Display 1：40px/900/-0.04em（页面大标题）
- Heading 1：28px/800/-0.03em（区块标题）
- Heading 2：20px/700/-0.02em（卡片标题）
- Body：15px/400/1.65（长文本）
- UI Label：13px/600（导航/按钮）
- Caption：11px/500/uppercase/0.08em（标签/徽章）

## 间距系统
基准 4px。卡片内边距 20-24px，大区块间距 32-48px，页面边距 24-32px。

## 圆角系统
- 小元素/输入框：6px
- 卡片/按钮：10px
- 大卡片/弹窗：14px
- 图标按钮：50%

## 阴影系统
- 轻：`0 1px 3px rgba(0,0,0,0.04)`
- 中：`0 4px 16px rgba(0,0,0,0.06)`
- 重：`0 20px 40px rgba(0,0,0,0.08)`
- 强调光晕：`0 8px 24px rgba(197,93,59,0.16)`

## 玻璃拟态（Glass）
- 背景：`rgba(251,250,249,0.78)` 浅色 / `rgba(18,16,14,0.78)` 深色
- 边框：`1px solid rgba(255,255,255,0.08)` 深色 / `rgba(0,0,0,0.04)` 浅色
- backdrop-filter: blur(16px)

## 动效系统
- 默认缓动：`cubic-bezier(0.22, 1, 0.36, 1)`
- 弹性缓动：`cubic-bezier(0.34, 1.56, 0.64, 1)`
- 微交互：150ms
- 页面/卡片入场：300-400ms
- Stagger：每个元素延迟 50ms

## 图标规范
- 全部使用 SVG，禁止使用 emoji 作为图标。
- 线条风格：1.5px stroke，24×24 viewBox，round caps。
- 专家头像使用抽象几何 SVG 而非 emoji 头像。

## 组件原则
- 按钮：实心主按钮（强调色）+ 幽灵按钮（边框）+ 文字按钮。
- 输入框：底部细线或浅边框，聚焦时强调色光晕。
- 卡片：细边框 + 极淡阴影 + hover 微上浮。
- 标签/徽章：小字大写 + 圆角 + 半透明背景。
- 导航：左侧玻璃侧边栏，图标 + 文字，active 态强调色竖线。

## 反模式（严禁）
- 使用 emoji 作为图标
- 蓝紫渐变主色
- 纯白背景（浅色主题用暖白）
- 圆润一切（混合直角与小圆角）
- 大面积投影扩散
- 无动画的静态交互

## 响应式策略
- 桌面：三栏固定侧边栏（左 220px，右 380px），中间弹性。
- 平板：右侧设定面板可折叠。
- 手机：单栏，侧边栏通过 bottom sheet 或 drawer 展开。
