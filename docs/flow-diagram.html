三个关键节点
节点 A
📝 沉淀瞬间
用户点「总结」，AI回复从对话流固化为工作台文档。同类型文档自动追加 ## 副标题。
✅ 已实现
节点 B
🔒 定稿瞬间
设定从"可变"变"冻结"。locked后不可编辑，作为不可变真相注入AI。
draft → finalized → locked
✅ 已实现
节点 C
⚡ 自动触发
章节 finalized 时，后台自动更新编年史。这是目前唯一的自动闭环。
✅ 已实现
主线的断点（缺失环节）
✗
沉淀时没有知识提取 — 总结入工作台时，没有自动提取实体/关系（角色、地点、势力）到知识图谱
✗
定稿时没有一致性检查 — 没有 Lint 机制扫描文档找矛盾（境界跳级、地理矛盾、时间线冲突）
✗
章节定稿没有触发伏笔扫描 — 不会自动检测哪些伏笔被 planted/hinted/revealed
✗
没有创作-验证分离 — 所有 AI 操作都是"自己写自己评"，没有独立的审校 Agent
✗
没有"建议下一步"引导 — 用户不知道当前该做什么（补世界观？写角色？推进章节？）
✗
编年史注入只读 locked 世界观 — finalized 状态的世界观完全被忽略，AI 可能编造未锁定设定
